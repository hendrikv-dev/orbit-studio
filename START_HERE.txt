ORBIT STUDIO — START HERE

1. Extract this ZIP into a new folder.
2. Double-click START_ORBIT_STUDIO.command.
3. Keep the Terminal window open while Orbit Studio is running.
4. Press Control-C in Terminal to stop it.

The first launch installs fresh dependencies directly on your Mac. This avoids the invalid native Rollup binary that can result when node_modules is copied between systems or packaged inside a ZIP.

Do not double-click index.html. Orbit Studio is a Vite application and must run through the launcher.
