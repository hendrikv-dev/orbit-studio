# Current Product Anti-Patterns

This list applies the Constitution to the current Explorer and Playground. It is not a second source
of product principles.

Avoid:

- Treating placeholder names as approved branding.
- Making Explorer feel like a database or Playground feel like object-management software.
- Adding features to solve visual hierarchy problems.
- Adding atmosphere, clouds, terrain, labels, or other effects solely to create a premium
  appearance when they obscure the information hierarchy or scientific meaning.
- Permanent interface panels that compete with the visualization when capability can remain
  accessible contextually.
- Labels everywhere as a substitute for rendering hierarchy.
- Parallel renderers, clocks, resolvers, or selected-object paths that can produce different truths.
- Broad architecture rewrites during stabilization without an identified root cause and migration
  plan.
- Performance fallbacks that silently freeze, fabricate, reclassify, or omit scientific state.
