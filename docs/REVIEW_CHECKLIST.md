# Orbit Studio Product Review Prompts

This is a supplementary product-review aid. `AGENTS.md` defines the required engineering lifecycle,
validation, re-engagement loop, and completion criteria. The Constitution defines product
principles. Checking these prompts does not establish completion.

Use the relevant prompts after satisfying the requirement-to-evidence review in `AGENTS.md`.

## Explorer

- Does Explorer communicate the orbital environment without making a database the focal point?
- Does the spatial visualization remain the primary surface?
- Are objects and orbits legible at far, mid, and close zoom without indiscriminate enlargement or
  labeling?
- Do time, catalog membership, rendered state, provenance, warnings, filters, and selection tell one
  consistent story?
- Are unavailable, reconstructed, source-record, and model-derived states distinguishable without
  unnecessary visual clutter?

## Playground

- Does Playground begin with an understandable orbital scenario?
- Does it feel like direct manipulation rather than object administration?
- Is advanced complexity progressively disclosed without hiding essential scientific assumptions?

## Cross-workspace

- Did capability remain discoverable while unnecessary persistent interface weight was avoided?
- Are keyboard, focus, responsive, loading, empty, and failure states coherent?
- Does machine-readable review state agree with the captured runtime and renderer output?
- Did the change reduce or avoid duplicate product logic rather than moving complexity elsewhere?
